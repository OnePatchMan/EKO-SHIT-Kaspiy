# Эко-Щит Каспия — веб-приложение

Java/Spring Boot сервер и веб-интерфейс инспектора. Нейросеть работает отдельным HTTP сервисом; исходники находятся в ai/, веса и установленные зависимости не включаются в Git.

## Схема

Браузер → Java :8080 → внешний EcoShield AI :8001 → Java и база → дашборд.

Отдельный сервис: готовая YAMNet для аудио и явно обозначенный сценарный расчёт условий нереста сазана. Код по имени файла и локальные псевдопрогнозы удалены. При недоступности внешнего сервиса Java возвращает503; некорректные данные получают422. Результаты не подменяются демонстрационными ответами.

## Запуск

Требуются JDK25 и Maven либо Maven Wrapper из demo. Сначала запустите EcoShield AI из ai/ по его инструкции. Веса загружаются при первом запуске и остаются вне Git.

PowerShell из корня веб-репозитория:

```powershell
$env:ECOSHIELD_AI_SERVICE_URL='http://127.0.0.1:8001'
Set-Location demo
.\mvnw.cmd spring-boot:run
```

Откройте http://localhost:8080. Проверка модели видна через /api/system/status. Первый запуск Maven требует доступа к зависимостям. Unix: ./run.sh (JDK25 и Maven на PATH).

Если Python работает на другом сервере, ECOSHIELD_AI_SERVICE_URL содержит адрес, доступный Java серверу. localhost всегда относится к машине/контейнеру самого Java процесса. Браузер обращается только к Java; для модели используйте внутреннюю сеть или защищённый HTTPS доступ.

## Данные и ограничения

Встроенные станции, аудиопримеры и исходная телеметрия служат демонстрации и не доказывают подключение реальных гидрофонов. По умолчанию происхождение прогноза demo_synthetic. Даты без пояса интерпретируются в Europe/Moscow; единицы уровня переводятся из сантиметров в метры только при известном нуле поста. Данные об обводнении не выдумываются.

Оценка звука не равна вероятности браконьерства. Неопределённость и отсутствие целевого события не означают, что акватория безопасна. Сценарный расчёт условий не является подтверждённой вероятностью нереста.

Актуальный контракт: [INTEGRATION_GUIDE.md](INTEGRATION_GUIDE.md). Старые PLAN/TODO/BACKEND_DOCS/TESTING_AND_RUN отражают прежний прототип; описание встроенного ИИ, заглушек и результаты прошлых тестов не являются приёмкой этой интеграции.

## Общий запуск

В корне репозитория: `docker compose up --build`. Веб-интерфейс http://localhost:8080; модель доступна Java по внутреннему адресу http://ai:8001. Первый запуск загружает Python зависимости и официальные веса; веса хранятся в отдельном Docker volume и не попадают в Git. Конфигурация Docker Compose требует отдельной проверки на машине с Docker; локальную связку проверяем через Java и Python процессы.
