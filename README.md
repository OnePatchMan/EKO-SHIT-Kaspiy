## 📌 О проекте

«Эко-Щит Каспия» — программно-аппаратный комплекс и цифровой помощник инспектора особо охраняемых природных территорий (ООПТ) Каспийского бассейна (дельта Волги, Астраханский биосферный заповедник, Дагестанский заповедник, остров Тюлений).

Платформа объединяет:
1. **IoT-мониторинг гидрологии в реальном времени:** приём и непрерывный анализ параметров воды с автономных буев (кислород $O_2$, температура, солёность, $pH$, мутность, уровень воды) с автогенерацией алертов при экологических аномалиях (гипоксия/замор).
2. **Акустическую ИИ-аналитику:** нейросетевое распознавание звуков браконьерских лодок (высокооборотистые подвесные моторы типа «Байда») и выстрелов по гидроакустическим сэмплам.
3. **Предиктивный гидробиологический модуль:** моделирование условий нереста и миграции ценных осетровых рыб (*Acipenser gueldenstaedtii*) для упреждающей дислокации патрулей.
4. **Интерактивный дашборд инспектора:** геоинформационная карта (Leaflet) с цветовой индикацией состояния постов, оперативная лента событий, графики динамики (Chart.js) и плеер прослушивания гидроакустических записей.

## 🚀 Быстрый старт

### Требования:
- Java 21+ (рекомендуется OpenJDK 25/27)
- Maven 3.9+ (или системный `mvn`)

### Запуск одной командой:
```bash
./run.sh
```

После старта откройте в браузере:
- 🌐 **Интерфейс инспектора:** [http://localhost:8080](http://localhost:8080)
- 🗄️ **Консоль базы данных H2:** [http://localhost:8080/h2-console](http://localhost:8080/h2-console) (JDBC URL: `jdbc:h2:mem:ecoshield_db`, User: `sa`, пароль пустой)

## 🛠️ Скрипты и утилиты

- `run.sh` — запуск бэкенда и встроенного веб-интерфейса.
- `test_endpoints.sh` — автоматическая проверка всех REST-эндпоинтов.
- `scripts/import_real_data.py` — загрузка реальных замеров из CSV и реальных WAV-аудиофайлов.
- `scripts/ai_service.py` — готовый Python FastAPI микросервис для Участника 3.
- `data/caspian_real_telemetry.csv` — калиброванный датасет осенней гидрологии Каспийского бассейна.
- `data/audio/` — 16-bit PCM WAV аудиофайлы (моторы лодок, выстрелы, всплески, прибой).
