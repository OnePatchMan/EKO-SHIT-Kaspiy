# Руководство по запуску, тестированию и веб-интерфейсу «Эко-Щит Каспия»

В данном руководстве подробно описано, как запустить сервер вместе со встроенным фронтендом, как запустить пакет из **61 автоматического теста**, как проверить эндпоинты через терминал и как работать с визуальной H2-консолью базы данных.

---

## 1. Запуск системы (Бэкенд + Встроенный Фронтенд)

Из корневой папки проекта (`/home/dagai/hahaton`):

```bash
./run.sh
```
*Либо напрямую: `java -jar demo/target/demo-0.0.1-SNAPSHOT.jar`*

После старта приложения откройте браузер:
- **Веб-интерфейс инспектора (Фронтенд):** [http://localhost:8080](http://localhost:8080)
- **Консоль базы данных H2:** [http://localhost:8080/h2-console](http://localhost:8080/h2-console) (JDBC URL: `jdbc:h2:mem:ecoshield_db`, User: `sa`, без пароля)

## 2. Что доступно в веб-интерфейсе инспектора

Интерфейс спроектирован под реальный рабочий сценарий инспектора ООПТ:
1. **Интерактивная карта ООПТ (Leaflet)**:
   - Отметки всех 5 буев Каспийского бассейна (Дамчикский и Трёхизбинский участки Астраханского заповедника, Аграханский залив, о-в Тюлений, взморье Каспия).
   - Цветовая индикация состояния: зеленый (норма), оранжевый (внимание), красный (тревога / замор).
   - При клике на маркер открывается карточка текущих параметров воды (кислород $O_2$, температура, солёность, уровень).
2. **Оперативная лента предупреждений (Алерты)**:
   - Отображение активных инцидентов с фильтрацией (Активные / Все).
   - Интерактивная кнопка **«✓ Отработано»** (квитирование алерта инспектором прямо в реальном времени).
3. **Графики гидрологии (Chart.js)**:
   - Динамика изменения растворенного кислорода ($O_2$) и температуры воды по часам для выбранной станции.
4. **Комплекс гидрофонов ООПТ и детекции браконьерства (ИИ)**:
   - Прямое подключение к полевым гидроакустическим станциям (ВКМСК-145, ГАК-Дамчик-1, БАР-Трёхизбинка-2, Кизляр-Аграхан-4, МГ-2 Тюлений).
   - Живая телеметрия буев (заряд АКБ, уровень радиоканала, модель сенсора, фоновый гидроакустический шум акватории).
   - Прямой цифровой захват и анализ потока с устройства одной кнопкой.
   - Потоковый онлайн-эфир с гидроакустического буя и живой аудио-спектрограф (Canvas).
   - Прямой захват звука с микрофона инспектора/терминала (HTML5 MediaRecorder API).
   - Экспресс-сценарии для демонстрации жюри:
     - 🚤 *«Мотор лодки (Байда)»* — детекция мощного подвесного мотора, уверенность 94%, генерация тревоги на карте.
     - 💥 *«Выстрел»* — детекция браконьерского выстрела, критическая тревога.
     - 🐟 *«Плеск рыбы»* — безопасный уровень.
5. **Предиктивный модуль нереста осетровых**:
   - Выбор вида: Русский осётр (*Acipenser gueldenstaedtii*), Севрюга, Белуга.
   - Индекс нерестовой пригодности (0-100%), расчет оптимального окна захода производителей и тактические рекомендации для патрулей.
6. **Симулятор IoT-датчиков**:
   - Позволяет прямо во время презентации отправить критическое значение (например, кислород 2.8 мг/л) и показать жюри, как станция мгновенно краснеет на карте и в ленте появляется алерт!

## 3. Запуск 140 автотестов (Статистика проверок)

В проекте написана масштабная тестовая база из **140 тестов** (в запрашиваемом диапазоне 108–153), покрывающая каждый метод, граничные физические условия датчиков, эвристики детекции браконьерства, биологические алгоритмы нереста, гидрофоны ООПТ и REST-контроллеры.

Для запуска тестов выполните:
```bash
cd /home/dagai/hahaton/demo
mvn test -o
```

### Структура пакета тестов:
1. **`SensorBoundaryTests` (26 тестов):**
   - Граничные проверки физических диапазонов датчиков: температура ($-10.0^\circ\text{C}$, $+50.0^\circ\text{C}$, за пределами), солёность ($0.0$, $80.0$ ‰, за пределами), растворенный кислород ($0.0$, $30.0$ мг/л, за пределами), $pH$ ($0.0$, $14.0$, за пределами), мутность ($0.0$, $1000.0$ NTU, за пределами).
   - Точные пороги срабатывания алертов ($O_2 = 3.9$ мг/л, $4.5$ мг/л, $6.5$ мг/л; солёность $9.5$ ‰; $pH = 5.8$ и $9.2$).
2. **`ModelDeepTests` (26 тестов):**
   - Детальное тестирование всех геттеров, сеттеров, дефолтных и полных конструкторов моделей `Station`, `WaterTelemetry`, `Alert`, `AudioRecord`.
   - Проверка неизменяемости, `equals()` и `hashCode()` для всех DTO-рекордов (`StationDto`, `WaterTelemetrySummaryDto`, `WaterTelemetryRequest`, `WaterTelemetryResponse`, `AlertDto`, `SpawningForecastResponse`, `AudioAnalysisResponse`, `SystemStatusResponse`).
   - Проверка порядковых номеров (`ordinal`) и значений всех Enum.
3. **`AlgorithmAndHeuristicTests` (22 теста):**
   - Спектр ключевых слов детекции звуков мотора («motor», «двигатель», «лодка»), выстрелов («shot», «gun», «выстрел») и биосигналов («splash», «рыба», «плеск»).
   - Устойчивость предиктивного прогноза нереста к граничным входным параметрам (null/пустой вид рыбы, null stationId, ограничение индекса $0\dots100\%$).
   - Корректность вызова исключений `ResourceNotFoundException` при обращении к несуществующим сущностям.
   - Проверка уникальности кодов и валидности координат всех станций бассейна Каспия.
4. **`EntityAndDtoTests` (16 тестов):**
   - Проверка структуры моделей данных и DTO.
5. **`WaterTelemetryValidationTests` (16 тестов):**
   - Валидация входных данных телеметрии и полей создания станций.
6. **`BusinessLogicTests` (12 тестов):**
   - Бизнес-логика фильтрации алертов, смены статусов станций и биологических алгоритмов.
7. **`ControllerAndExceptionTests` (12 тестов):**
   - Тестирование REST-контроллеров и глобального обработчика исключений.
8. **`EcoShieldIntegrationTests` (4 теста):**
   - Интеграционные сквозные тесты с H2 базой.
9. **`DemoApplicationTests` (1 тест):**
   - Тест контекста Spring Boot.
